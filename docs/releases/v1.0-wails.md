# TheOne v1.0

## 待处理状态通知

- 自定义通知新增可单独勾选的「待处理状态变化（含全部清除）」事件，汇总等待回答、权限审批，以及任务完成或普通会话结束后的未读状态。
- 多个会话分别处理：只有全部等待解除、全部未读清除后，才发送清除状态。原有三类通知保持原来的默认订阅方式。
- 状态通知独立保留最新一条，普通事件队列满时也不会丢掉最后的清除状态；保存配置、窗口重新聚焦时可重新同步当前状态。
- 禁用或更换通知程序时向旧程序发送清除状态；正常退出时也会尽力清除。调用结果仅保留在内存中，正式版不写应用调试日志。

## Magic Bay Light 接入

- 提供只依赖 Python 标准库的灯光脚本：有询问、权限审批或未读结束会话时亮灯，全部处理完毕后熄灯。
- 重复状态先读取设备，状态一致时不重复写入；保留现有自动亮度和辅助配置，不刷固件。
- 「保存并发送测试事件」会短暂点亮并恢复原状态；设备未连接时明确报告测试失败。
- 增加独立的 [Magic Bay Light 接入文档](https://github.com/gp-alex-chen/claude-session-manager/blob/v1.0-wails/docs/magic-bay-notifications.md)，包含脚本配置、手动验证和支持范围。当前脚本仅支持已验证的 Lenovo Magic Bay Light 1.01；强制退出、掉电或设备断开时无法保证熄灯。

## 额度圈布局

- 订阅额度圈移到侧栏左下角，设置按钮靠左，Agent 名称和额度圈靠右。
- 点击额度圈后详情向上展开；更新提示单独换行，避免挤占底栏两侧控件。

## 下载与接入

- Windows 用户下载 `TheOne.exe`；`claude-terminal.exe` 是供旧版更新器使用的同内容兼容文件。
- 自定义通知的新汇总事件需要手动勾选。使用外设灯时，在「设置 → 通知」配置 Python 和脚本路径，并只勾选「待处理状态变化（含全部清除）」。
- 完整协议与其他程序接入方式见 [自定义通知程序文档](https://github.com/gp-alex-chen/claude-session-manager/blob/v1.0-wails/docs/custom-notifications.md)。
