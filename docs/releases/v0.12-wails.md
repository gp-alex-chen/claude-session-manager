## 更新内容

- 应用更名为 **TheOne**，启用全新 TO 合字图标。
- 新增 **Codex 支持**：新建与恢复会话、原生重命名、任务状态及按模型统计 Token 用量。
- 新增 **订阅额度圆环**：跟随当前 Claude/Codex 会话，显示 5 小时和周剩余额度；每 15 分钟刷新，支持手动刷新，API 模式暂停自动查询。
- 新增 **任务栏完成角标**：显示已完成、未查看的会话数量，查看后自动减少。
- 优化 **多会话布局**：支持 Agent 筛选、会话搜索、项目与 Agent 信息展示，以及下拉选择交换窗格会话。
- 设置与会话数据统一保存到 `%LOCALAPPDATA%\ClaudeSessionManager`，更换 exe 名称或目录不影响读取。

Windows x64：`TheOne.exe` · 版本：`v0.12-wails`
