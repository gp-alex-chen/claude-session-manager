# TheOne v1.1

## Codex 启动与环境变量兼容

- 修复 Windows 官方安装器已安装 Codex、普通 cmd 可以运行，但 TheOne 新建会话仍提示“未检测到 Codex CLI”的兼容问题。
- 保留当前 PATH 的查找优先级；当前进程 PATH 找不到时，补查官方原生安装目录，以及 `CODEX_INSTALL_DIR` 指定的绝对安装目录。
- 将已解析的 Codex 原生程序目录加入该会话终端的 PATH，保留原有工具路径，避免后续 cmd 启动再次查找失败。
- 不修改 Windows 用户或系统环境变量，不写入全局 Codex 配置；正式版不启用应用调试日志。

## 使用说明

- Windows 用户下载 `TheOne.exe`；`claude-terminal.exe` 是供旧版更新器使用的同内容兼容文件。
- 本次仅发布 Codex 安装路径和终端环境兼容修复。共享 app-server、会话引用等开发中的功能不包含在本版本中。
- 如果使用自定义安装目录且仍无法找到 Codex，请确认 `CODEX_INSTALL_DIR` 或 PATH，并从环境已更新的启动器重新启动 TheOne。此修复不会实时刷新所有环境变量。
