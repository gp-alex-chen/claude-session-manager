## 更新内容

### 自定义通知程序

- 新增「设置 → 通知」，可在等待回答、等待权限审批或任务完成时，调用用户自定义的程序。
- 支持 Python、Go exe、Node.js、PowerShell 等，通过标准输入接收 UTF-8 JSON；可配置启动参数、工作目录、超时和触发事件。
- 新增「保存并发送测试事件」按钮，界面显示执行状态、排队数量和最近一次调用结果，方便接入自己的本地服务器或通知渠道。
- 同一种等待状态持续存在时不重复通知，启动时不补发已有状态。调用后台串行执行，失败不自动重试；超时、取消或结束时清理本次调用派生的 Windows 子进程。
- 提供独立使用文档、Python/Go HTTP 转发示例和本地接收服务器示例：[自定义通知程序接入指南](https://github.com/gp-alex-chen/claude-session-manager/blob/v0.100-wails/docs/custom-notifications.md)。

### 分屏会话拖动

- 按住终端标题栏左侧的 Agent 图标，可拖到其他分屏交换会话；目标为空窗格时直接移入。
- 目标窗格会高亮提示，松开后焦点跟随被拖动的会话；终端进程和输出保持不变。支持上下/左右双屏、三分屏、四分屏及 Claude/Codex 混合使用。

### 状态提醒

- 执行中改为对应 Agent 的绿色产品图标缓慢顺时针旋转，每 6 秒一圈；系统启用减少动态效果时保持静止。
- 任一会话等待回答或权限批准时，Windows 任务栏图标优先显示红色叹号。等待解除或会话关闭后，恢复尚未查看的完成数量角标。
- 查看或聚焦会话不会清除仍在等待处理的叹号，多会话等待时会持续提醒，直到全部解除。

### 修复与隐私

- 修复 Codex 启动时可能因较大的 `plugin/list` 响应超过旧消息上限而断开、提示重连的问题。中继双向单条消息上限统一提高到 64 MiB，并保留消息原样转发和大小边界检查。
- 移除测试中写死的本机项目路径，将通知配置加入 Git 忽略规则，避免误提交用户程序参数中的认证信息。
- 发布版继续默认不写应用调试日志；自定义通知的调用结果仅保存在内存，重启后清空。

### 使用说明

- 自定义通知默认关闭，需在设置中配置并启用。事件包含状态、会话名称和项目路径，不包含询问正文、待审批命令或对话内容。
- 通知基于观测到的状态变化，极短暂且未被轮询或更新捕获的中间状态可能不触发。
