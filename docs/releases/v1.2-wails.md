# TheOne v1.2

## 原生会话引用与通信

- 从侧栏把已有 Codex 会话拖入新建会话的终端正文，简短的 `@会话引用` 会插入当前草稿；不会自动发送，也不会清空已有输入。
- 新建会话通过 Codex 官方动态工具协议提供 `theone_threads.list_references`、`read_thread` 和 `send_message_to_thread`：读取被引用会话，或按用户明确指令给目标发送消息。
- TheOne 不再创建会话 MCP 服务，也不注入会话 MCP 配置、凭据或目录检查；用户自行配置的 MCP 保留原行为。
- 发送要求目标在当前 TheOne 中唯一在线且处于空闲状态。收到的消息和后续回答会显示在目标原生终端，原有未提交草稿继续保留。结果未知时不自动重发，重复调用不会重复发送。

## 共享 Codex 服务与稳定性

- 一个 TheOne 实例按需启动并共用一个原生 app-server，各终端和历史、额度等查询保留独立连接；关闭一个终端不会停止其他会话。
- 退出或更新时先确认并保存会话，再关闭终端和共享服务；服务异常退出后，新连接可以启动新的服务，不自动重放任务。
- 修复生成会话标题的临时任务被误识别为身份切换、导致引用授权丢失的问题。
- 在原生协议中补齐省略的项目目录，避免共享服务使新会话采用错误目录；项目路径不经过 Shell 参数拼接。
- 补齐工具调用的超时回包、取消、重复请求和迟到调用处理，保留对应原生终端的审批交互。

## 使用与兼容说明

- 旧版会话保留原 UUID 和历史，可继续作为读取或发送目标；要使用本组原生工具，请在 TheOne 中新建 Codex 会话，再拖入旧会话。
- 本版新建并保存过的会话，恢复后可继续使用原生工具，但需要重新拖入引用授权。能力记录只保存 UUID 和工具版本，不保存授权或凭据。
- 本组工具由 TheOne 宿主通过原生协议执行，需要在 TheOne 中使用。本轮验证版本为 Codex CLI 0.162.0；不会复制会话、改写私有历史或修改全局 Codex 配置。
- Windows 用户下载 `TheOne.exe`；`claude-terminal.exe` 为旧版更新器提供同内容兼容文件。正式版不启用应用调试日志。
- 具体操作与限制见 [会话引用文档](https://github.com/gp-alex-chen/claude-session-manager/blob/v1.2-wails/docs/session-references.md)。
