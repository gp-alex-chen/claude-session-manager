## v0.11-wails 更新内容

### 输入体验

- 修复 Windows 搜狗拼音输入 `abcd` 后按 `Shift` 切换英文时，候选框消失但文字未进入终端的问题。
- 不再强制结束输入法组成过程，保留其他输入法的正常提交和终端按键去重行为。

### 更新界面

- 检查更新时展示对应 GitHub Release 的中文说明，支持标题、列表、行内代码和安全的 HTTPS 链接。
- 下载时只显示一次进度百分比，并改善进度条文字的完整性和颜色对比度。

### 更新可靠性

- 下载时核对 Release 资产的 SHA-256、实际下载大小和 Windows PE 文件头；校验成功后才显示 100%。
- 保存打开会话失败时取消更新，不提前关闭终端；新版启动失败时尝试恢复旧程序。
- 旧版备份使用独立文件名，避免残留备份阻止下次更新。

### 构建信息

- Windows x64：`claude-terminal.exe`
- 版本：`v0.11-wails`
