# TheOne v1.5.1

## 会话列表与启动

- 归档按来源更新。某个来源不可用时，其他来源的归档仍可查看，失败来源保留上次读取的记录。
- 会话列表与归档计数共用一次历史读取。数据没有变化时，定时刷新不再重绘侧栏或重复预取项目用量。
- 自动恢复的第一个可见窗格可以立即输入，其他来源继续在后台加载。已经选中的窗格或输入框会保留焦点。
- 只有存在待恢复的 Antigravity 会话时才创建恢复批次。

## 升级与额度

- 升级先保存完整的会话恢复清单，再关闭终端。清单写入失败时取消升级，原终端可继续使用。
- 收到新的 Antigravity 额度回调后自动刷新圆环。关闭最后一个提供额度的终端后，旧额度会自动清除。

Windows 用户可在设置中检查更新，或下载 `TheOne.exe`。兼容资产 `claude-terminal.exe` 与正式下载内容相同，供旧版更新器使用。
