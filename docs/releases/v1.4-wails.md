# TheOne v1.4

## Codex 重置卡

- 在 Codex / ChatGPT 订阅详情中新增「查看重置卡」按钮，点击后才查询可用数量和卡片明细。
- 打开或重新打开额度详情、切换额度来源、刷新普通额度和定时轮询，都不会触发重置卡明细查询。
- 展示服务返回的可用总数、卡片名称、重置类型、说明及到期时间；没有提供卡片信息时显示说明，不当作零张。
- 可选择「使用这张」，再次确认后兑换；只有数量而没有明细时，可明确选择由服务端使用下一张。
- 未知类型、不可用或已过期卡片不提供使用入口。缺少可核对的账户标识时保留展示并说明暂不可使用。

## 使用结果与稳定性

- 重复点击不会产生新的兑换请求；使用前重新核对账户及所选卡片，使用后读取实际额度和卡片数量。
- 结果未知时提供「核对上次使用结果」，沿用同一个请求标识，不自动另外消耗一张卡。
- 已确认成功、但最新额度读取失败时，保留成功结果并提示刷新；核对旧请求时不会回显旧账户或旧额度快照。
- 普通额度读取与重置操作串行处理，迟到的旧查询不会覆盖新额度，查询状态也会正确结束。

## 使用与下载说明

- 需要当前 Codex CLI 和账户提供官方重置卡接口。卡片信息及核对状态仅保存在本次应用运行的内存中，不写入配置或日志。
- 若使用结果未知，建议先核对再退出；应用重启不会自动恢复或重试兑换。
- Windows 用户下载 `TheOne.exe`；`claude-terminal.exe` 为旧版更新器提供同内容兼容文件。
- 正式版不启用应用调试日志。自动测试使用模拟卡片，不消耗真实重置卡。
