# TheOne v1.3

## 自选订阅额度来源

- 点击侧栏底部的额度圆环，在详情顶部选择「自动跟随会话」「Codex / ChatGPT」或「Claude」。
- 选择后立即生效并自动保存，重启后恢复；默认仍跟随当前会话和分屏窗格焦点。
- 固定来源后，切换 Claude/Codex 会话不再改变额度显示；没有打开会话时也能查看所选来源的额度。
- 圆环名称、详情、刷新和自动查询均使用所选来源。查询失败或未登录时保留选择，迟到响应不会覆盖另一来源的显示。
- Claude 通过转换程序使用 ChatGPT 的用户，可以固定选择 Codex / ChatGPT。显示的是本机所选 CLI 当前登录账户的额度，需要登录对应账户；不会自动识别转换程序里的其他账户。

## 修复 Codex 完成状态

- 修复任务已经结束并回到输入提示，侧栏仍保持绿色执行状态的问题。
- Codex 后台生成标题的临时任务不再改变主会话的执行状态，也不会误阻止其他会话发送消息。
- 当前主会话的新任务仍会正常进入执行状态；完成、失败和中断状态继续分别显示。
