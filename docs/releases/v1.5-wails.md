# TheOne v1.5

## Antigravity CLI

- 新增 Google Antigravity 会话，可在项目中创建、打开原生历史，并与 Claude、Codex 混合分屏使用。
- 通过官方状态行同步任务状态、审批等待与会话标题；自动生成的标题会在后续历史刷新时同步。
- 正常退出或更新后，自动恢复已经确认身份并保存到原生历史的会话；未确认或身份切换有歧义的终端不会被误恢复。
- 自动查找 PATH、用户 `.local/bin` 和默认安装目录中的 `agy`。首次使用前请在自己的终端完成 CLI 配置与登录。

## 额度显示

- 额度来源新增 Antigravity，支持手动选择或自动跟随当前会话。
- Gemini 与第三方模型分别展示圆环，同组短周期和周额度使用双层圆环；模型组与圈层随实际返回的数据自动增减。
- 额度读取使用官方终端回调，保留真实零额度；缺失或不可换算的数据会显示说明。需要刷新原生额度时，可在 Antigravity 中运行 `/usage` 后读取终端额度。

## 启动与稳定性

- 本地布局和主题加载完成后即可操作，历史查询与自动恢复在后台按来源分别进行，不覆盖用户随后打开或选择的会话。
- 应用内复用一个 Antigravity 元数据 ACP 进程，避免每次查询都重复启动和初始化；首次冷查询仍可能需要数秒。
- 加强查询取消、进程回收、会话关闭与恢复的生命周期隔离，查询失败不会清空其他来源的可用历史。
- 后台进程不分配控制台窗口，PowerShell 宿主跳过 profile；托管的 Antigravity 进程禁用自身后台自动更新，以减少辅助进程弹窗。CLI 更新请在普通终端运行 `agy update`。

## 使用与下载说明

- Windows 用户下载 `TheOne.exe`；`claude-terminal.exe` 为旧版更新器提供同内容兼容文件。
- 需要支持官方状态行、会话级设置与 ACP 会话列表的 Antigravity CLI；本次真实集成验证使用 1.5.9。
- 会话恢复覆盖正常退出与更新，不承诺崩溃或断电后的恢复。Antigravity 成功通知和 Token 用量暂不支持。
- 正式版不启用应用调试日志。
